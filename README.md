# Movie App

Movie App is a modern React-based application that provides up-to-date information about movies, TV series/shows, and popular actors. The project follows the **Feature Driven Design (FDD) architecture**, ensuring scalable and maintainable code. It utilizes **Redux Toolkit** for state management and **Material UI** for a sleek and responsive design.

## Technologies
- **React** - for building the user interface.
- **Redux Toolkit** - for efficient global state management.
- **React-Redux Hooks (`useSelector`, `useDispatch`)** - for handling the store.
- **Material UI** - for modern styling and UI components.
- **Feature Driven Design (FDD)** - for structuring the application into modular features.
- **REST API** - for retrieving real-time movie, TV show, and actor data.

## Features
- Browse **movies, TV series/shows, and popular actors**.
- View detailed movie/TV show information, including **trailers**.
- Check **trending and upcoming movies**.
- Modern and responsive UI with **Material UI components**.
- Follows the **Feature Driven Design (FDD)** approach for a scalable architecture.

## How to Run the Project
1. Clone the repository to your local machine:
   ```bash
   git clone https://github.com/vitalii-khrypko/Movie-App.git
2. Navigate to the project folder and install dependencies:
  ```bash
  cd Movie-App && npm install
  ```
3. Run the project locally:
  ```bash
  npm start
  ```

The project will start a development server and open the app in your default browser.
